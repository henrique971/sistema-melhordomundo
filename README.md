# ⚽ Craque da Rodada

App de votação feito com React + Vite onde você escolhe quem foi o melhor jogador da rodada.

## Funcionalidades

- Votar em jogadores e remover votos
- Porcentagem e barra de progresso por jogador
- Destaque automático para o craque da rodada (líder)
- Ordenar por votos ou voltar à ordem original
- Zerar a votação

## Como rodar

```bash
npm install
npm run dev
```

Para gerar a versão de produção: `npm run build`.
